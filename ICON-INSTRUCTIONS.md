# 🎨 Creating App Icons

You need two PNG icons for the PWA to work:

## icon-192.png (192x192 pixels)
## icon-512.png (512x512 pixels)

### Theme Ideas
- Shadow Monarch crown 👑 with lightning ⚡
- AFL ball with purple/dark aesthetic
- "ARISE" text with dramatic background

### Quick Methods

**Option 1: Icon Generator**
1. Go to: https://www.favicon-generator.org/
2. Upload any image (Sung Jin-Woo, AFL logo, etc.)
3. Generate and download
4. Rename to `icon-192.png` and `icon-512.png`

**Option 2: Emoji Icons**
1. Open your phone emoji keyboard
2. Screenshot these emojis at large size: 👑⚡🏈
3. Crop to square
4. Resize to 192x192 and 512x512

**Option 3: Use Canva**
1. Go to canva.com (free)
2. Create 512x512 custom size
3. Add AFL/anime elements
4. Export as PNG
5. Resize one copy to 192x192

### Color Scheme
- Dark purple/blue (#1e3a8a)
- Shadow monarch purple (#8b5cf6)
- Lightning yellow (#fbbf24)
- Dark slate (#0f172a)

### What NOT to do
- Don't use copyrighted Solo Leveling artwork
- Don't use low-resolution images
- Don't use rectangular images (must be square)
